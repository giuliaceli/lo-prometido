# Lo Prometido

Seguimiento ciudadano de las promesas del gobierno peruano 2026–2031, contrastadas con hechos
fechados y con fuente.

Este repositorio sólo contiene la página publicada: https://giuliaceli.github.io/lo-prometido/

Para mostrarla dentro de otra web, usar `https://giuliaceli.github.io/lo-prometido/?embebido=1` en un iframe. En ese modo la
página oculta su título y avisa a la página que la contiene de su altura
(`{loPrometido: 'altura', valor}`) y de adónde desplazarse (`{loPrometido: 'ir', valor}`).
